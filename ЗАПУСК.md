# Как запустить

Нужен Python 3.9 или новее. Ставить ничего не нужно.

Из этой папки:

```bash
python3 report.py --date 10.11.2026 --data data --out out
```

Дата принимается и как `2026-11-10`, и как `10.11.2026`. День отчёта входит в расчёт.

На экране — текст. В папке `out/` появятся:

- `report-2026-11-10.txt` — тот же текст
- `works-2026-11-10.csv` — работы и строка «Не разнесено по работам»
- `contracts-2026-11-10.csv` — итог по каждому договору
- `payments-2026-11-10.csv` — какой платёж вошёл в выплаченное, а какой нет

CSV: разделитель «;», копейки через запятую, UTF-8 с BOM. В русском Excel открывается двойным щелчком. Если колонки не разъехались: Данные → Из текста/CSV, разделитель «;», десятичный разделитель «,».

В CSV по работам сложите колонки «к оплате», «выплачено» и «осталось» вместе со строкой `НЕ-РАЗНЕСЕНО`. Получатся итоги договора. Колонку «цена» складывать как долг не нужно: в ней есть и отменённые работы.

Папка `out/` в архиве — уже посчитанный отчёт на 10.11.2026. Команда выше перезапишет его.

Проверка расчёта:

```bash
python3 -m unittest discover -s tests -v
```
